# Выбор парадигмы и языка программирования

## Задача 1

**Парадигма:** Императивная 
**Язык программирования:** C++

**Обоснование:**  
Поток данных очень большой — около 3,2 ГБ/с, поэтому нужна высокая производительность и минимальные накладные расходы. C++ позволяет эффективно использовать многопоточность, SIMD/GPU и точно управлять памятью.



## Задача 2

**Парадигма:** Императивная
**Язык программирования:** Python

**Обоснование:**  
Главное требование — быстро сделать MVP и легко менять ML-алгоритмы. Python подходит лучше всего благодаря простой разработке и большому количеству готовых ML-библиотек.


## Задача 3

**Парадигма:** Реактивная
**Язык программирования:** TypeScript

**Обоснование:**  
Интерфейс получает много событий из WebSocket, API и действий пользователя, а виджеты зависят друг от друга. Реактивный подход удобно управляет такими зависимостями, а TypeScript добавляет типизацию и упрощает тестирование большого UI.


## Задача 4

**Парадигма:** Императивная  
**Язык программирования:** C

**Обоснование:**  
C требует минимум памяти, позволяет напрямую работать с регистрами и поддерживается практически всеми микроконтроллерами. Это также упрощает перенос прошивки между разными платформами.
